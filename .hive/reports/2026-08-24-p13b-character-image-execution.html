产品链与架构边界

Studio 创建任务→SQLite draft→GPU host lease→Comfy submit intent→恢复 / 轮询→candidate + 血缘→人工批准
层职责关键不变量
Protocol / Store独立 CharacterImageJob、事件、稳定失败码、migration v20/v21、source hash、retry lineage。原任务不可改写；一次原任务最多一个 retry；HTTP/JSON snake_case。
ProviderKrea/Qwen 确定性 graph、上传、queue/history、输出下载、完整像素解码。operation 决定 engine；LoRA 默认无；失败不造 placeholder。
Task enginelease claim、submit intent、同任务恢复、heartbeat、backoff、精确取消、orphan quarantine。恢复原 prompt，不盲目重提；晚到 worker 不能登记不属于自己的文件。
Completion原子落盘并在单 SQLite transaction 创建 Asset、Reference、derivation、完成 job。完成前再次验证 approved source 和 frozen hash；结果永远先是 candidate。
Studio三类表单、真实 job 状态、活跃轮询、取消/重试、候选预览、批准与 manifest stale CTA。不显示假进度；不自动批准；不自动冻结 manifest。

恢复、取消与 4090 并发

RECOVERY

provider I/O 前先持久化 provider_client_id。进程中断后从 queue/history 找同一 prompt；只有确认 queue/history 均不存在才允许重提。

EXACT CANCEL

运行中按本 job 的 prompt id interrupt/remove；API 保存非空原因。worker stop 通过 abort 退出，但保留可恢复任务状态。

ONE GPU HOST

H3 video 与 character image 共用 SQLite GpuLease；提交前后双查 8188/8190 队列，避免检查后竞争窗口。

  • /free 只发给 H3_MANAGED_COMFY_ENDPOINTS 显式列出的实例；默认列表为空。
  • 队列非空或响应畸形时 fail closed，不 free、不上传、不提交；随后按可恢复 timeout/backoff 处理。
  • 项目 generation lock 与活跃图片 job 双向互斥；同一 GPU host lease 也防止 H3 与图片 worker 并发占卡。
  • 完成事务前再次读取 source；母图若已不再 approved 或 hash 漂移，候选不得入库。
  • 自动恢复有指数退避和最大 8 次尝试；孤儿文件只隔离到 quarantine，不删除。
