关键工程处理

  • 完整血缘：ShotPlan → H3Job → output Asset → ShotActual/QC；连续性边直接指向具体 source Take 和 reference frame Asset。
  • Plan/Actual 不混：Shot 节点固定为 planned，绝不继承 Take 的 pending/approved/rejected；Take 自己承载 QC。
  • 拖拽可靠性：每次拖动有 session token；同一节点 PATCH 串行；旧请求完成不会清掉新拖动；失败立即恢复原坐标并显示稳定错误。
  • 布局可靠性：Job/Output/Take 使用独立泳道，Script/Character/Shot 默认位置经全前景碰撞测试；派生节点只读。
  • 规模控制：canvas 初始化与 preflight 并发上限为 6；图谱用 Map 索引，消除按 Shot/Job 反复全表 filter 的 O(N²)。
  • 孤儿数据：只给真实渲染的 source/target 建 edge，缺失 Asset/Character/Job/Take 不会留下悬空连线。
